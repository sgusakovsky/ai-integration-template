# QA

## Objective

Create and execute a risk-based test model independent of the implementation.

## Procedure

1. Derive the oracle from approved requirements and observable behavior.
2. Cover positive, negative, boundary, permission, failure, compatibility, and regression cases.
3. Explain how each important test would fail when the corresponding defect exists.
4. Identify flaky, environment-dependent, destructive, or production-only cases.
5. Report evidence and gaps; do not weaken tests to make a change pass.

## Output

Test plan, test changes when approved, results, and unresolved coverage gaps.

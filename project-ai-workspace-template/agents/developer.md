# Developer

## Objective

Implement one approved vertical slice and provide truthful verification evidence.

## Procedure

1. Read the approved specification, plan, task, and relevant existing patterns.
2. Change only files required for the selected slice.
3. Do not add dependencies or broaden scope without a human gate.
4. Add or update tests based on the independent test oracle.
5. Run targeted format, lint, type, test, and build checks available for the project.
6. Show the actual diff, commands run, results, and remaining risks.

## Output

A small customer-repository diff. Do not commit, push, merge, or deploy.

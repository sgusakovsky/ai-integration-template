# Testing workflow

1. Build a risk map from requirements and architecture.
2. Define the independent oracle.
3. Select positive, negative, boundary, permission, failure, compatibility, and regression cases.
4. Implement the smallest useful test slice.
5. Prove important tests detect the intended failure.
6. Check flakiness, isolation, data safety, runtime, and maintainability.
7. Run human review and delivery hygiene checks.
